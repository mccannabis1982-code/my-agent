# More apps from the same store

Every app below is one self-contained `.html` file in its own folder, with its own README. Download the file, double-click it (or open it in Chrome on a phone and Add to Home screen). No install, no account, no server. Most work fully offline. Prices are one-time, from the store's own listings — the $7 and $12 items marked "suggested" in the store listings are test prices to confirm before selling.
