Integrations — connect services with code

Honest label: this panel writes fetch code for legitimate public APIs you authorise — it does not log in to anything for you and it does not store any account. API keys are entered by you yourself and are never stored in this file. If a service needs a key, the drafted code shows a placeholder (YOUR_API_KEY_HERE) for you to replace with your own key, in your own copy of the code. The examples below need no key at all.

Example 1 — Weather forecast (Open-Meteo, no key)

fetch('https://api.open-meteo.com/v1/forecast?latitude=39.74&longitude=-104.99&current=temperature_2m,wind_speed_10m&timezone=auto')
  .then(function(r) { return r.json(); })
  .then(function(d) { console.log('Now in Denver:', d.current.temperature_2m, 'C, wind', d.current.wind_speed_10m, 'km/h'); });

Example 2 — GitHub public repos (no key)

fetch('https://api.github.com/users/octocat/repos?per_page=5&sort=updated')
  .then(function(r) { return r.json(); })
  .then(function(repos) { repos.forEach(function(repo) { console.log(repo.full_name, repo.html_url); }); });
Public repos only, no login. Unauthenticated calls are limited to 60 per hour. Replace octocat with any GitHub username.

Example 3 — Find a place's coordinates (Open-Meteo geocoding, no key)

fetch('https://geocoding-api.open-meteo.com/v1/search?name=Denver&count=1')
  .then(function(r) { return r.json(); })
  .then(function(d) { console.log(d.results[0].name, d.results[0].latitude, d.results[0].longitude); });
