Customize — keys, instructions, memory
Live search grounding is a Gemini feature. It needs your Gemini key; without one, no live results are shown and nothing is made up.
Pollinations — no key, no sign-in. Best-effort free lane: the anonymous limit is not published, so expect 402 errors under load — the app shows the retry time when one is given and suggests another brain. This lane may be retired without notice. Do NOT use the keyed API at gen.pollinations.ai — that one is paid.
OVHcloud AI Endpoints — no key, no sign-in. Anonymous tier: about 2 requests/minute per IP per model. That is why several models are listed — switching models raises your total throughput, because the limit is per model. If one model says "too many requests", try another OVH model or another brain. gpt-oss-120b is the strongest free model here. Models ending Feb 10, 2027 are not listed.
Puter.js — optional bonus brain, never the default. Sign in to your own free Puter account on first use (button below). Each user burns their own free monthly allowance, and its size is unpublished — Puter may ask you to top up. If you are not signed in, this brain stays out of Ask-all and Debate and tells you to sign in.
Cloudflare free limits (Workers Free plan): 10,000 Neurons/day, resets 00:00 UTC. Over the cap calls fail — they never bill you. 300 requests/min. No card stated for the free plan. Roughly 50–80 chat turns/day on the 70B/120B models, several hundred on the 8B. Paid-only models (e.g. Kimi K2, GLM-5, DeepSeek V4) return an error on the free plan — do not use them here.
Cloudflare browser warning — tested 2026-11-12: calling Cloudflare's API straight from this file is expected to FAIL in a browser. A probe found the API answers OPTIONS preflight requests with "405 OPTIONS not supported" and sends no CORS headers, so the browser blocks the call before it reaches Cloudflare. This is not a bug in your key or account. Working routes: (1) a tiny free Cloudflare Worker as a proxy — the Worker calls the API server-side, where there is no CORS; (2) the Termux Node agent, which has no browser restrictions. See the on-device setup doc for the Termux route. If Cloudflare ever adds CORS support, this brain will work directly.
Everything here is saved only in this phone's browser. Keys never leave your phone except to the AI company you chose. Free-tier chats may be used by the provider to improve its models — never paste passwords, your SSN, or private account details.
